## Installation & Usage

Add components directly to your Remotion project using the `malesngonten` CLI:

```bash
npx malesngonten add Terminal-Simulator
```

*(Or directly from GitHub:)*
```bash
npx github:malesngonten/malesngonten add Terminal-Simulator
```
